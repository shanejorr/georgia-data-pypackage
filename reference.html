Reference#

Every function, grouped as in the R package. Import the package as import georgiacivicdata as gcd.

List the datasets in the catalog.

search

Search the catalog.

Get a dataset's data contract.

Everything about one dataset, lookup table or geometry dataset.

Errors and advisories#

API errors keep the API's own code (such as "TOPIC_NOT_FOUND"), the HTTP status and the error's details. Catch GCDError for any of them, or a subclass for one kind of failure.

GCDError

Base class of every error from the Georgia Civic Data API or this package.

GCDNotFoundError

No such dataset, lookup table or path (HTTP 404).

GCDUnavailableError

The service couldn't answer: no connection, a timeout, a rate limit that outlasted the retries, or a server error (HTTP 5xx).

GCDPlaceNotFoundError

A district, school or county name matched nothing.

GCDPlaceAmbiguousError

A district, school or county name matched more than one place.

GCDCensusError

The U.S.

GCDAdvisory

An advisory about a result: suppressed values, totals that must not be added to their subgroups, a search with no good match, and so on.
